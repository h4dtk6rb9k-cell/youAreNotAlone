# ADR-002: Event-based cooldown для повторного чтения книг

## Статус: Принято

## Контекст

Повторное чтение «Руководства гражданина» ограничено игровыми событиями, не таймером. Между двумя прочтениями должно произойти хотя бы одно из:
- Завершён диалог с получением или закрытием квеста
- Произошёл бой
- Прошло ≥30 минут реального времени
- Identity вырос на ≥15 с момента последнего прочтения

Стек: Godot 4, GDScript.

## Решение

### Класс ReadCooldown

```gdscript
# core/read_cooldown.gd
class_name ReadCooldown

const COOLDOWN_SECONDS: float = 30.0 * 60.0
const IDENTITY_DELTA_REQUIRED: int = 15

var _last_read_time: float = -COOLDOWN_SECONDS   # сразу доступно при старте
var _identity_at_last_read: int = 0
var _quest_completed: bool = false
var _combat_occurred: bool = false

func can_read() -> bool:
    if _quest_completed: return true
    if _combat_occurred: return true
    if Time.get_unix_time_from_system() - _last_read_time >= COOLDOWN_SECONDS: return true
    if GameState.stats.identity - _identity_at_last_read >= IDENTITY_DELTA_REQUIRED: return true
    return false

func on_read(current_identity: int) -> void:
    _last_read_time = Time.get_unix_time_from_system()
    _identity_at_last_read = current_identity
    _quest_completed = false
    _combat_occurred = false

func on_quest_completed() -> void:
    _quest_completed = true

func on_combat_occurred() -> void:
    _combat_occurred = true
```

### Интеграция

`ReadCooldown` живёт в `GameState` как `GameState.book_cooldown`.

Подключения сигналов:

```gdscript
# В DialogueSystem:
quest_closed.connect(GameState.book_cooldown.on_quest_completed)

# В CombatSystem (v2, сейчас заглушка):
# combat_ended.connect(GameState.book_cooldown.on_combat_occurred)

# В Interactable книги:
func _on_interact() -> void:
    if not GameState.book_cooldown.can_read():
        UIManager.show_hint("Мысли ещё не улеглись.")
        return
    UIManager.open_book_reader()
```

### Сохранение cooldown

```gdscript
func save(config: ConfigFile) -> void:
    config.set_value("cooldown", "last_read_time", _last_read_time)
    config.set_value("cooldown", "identity_at_read", _identity_at_last_read)
    # _quest_completed и _combat_occurred не сохраняются — сбрасываются при перезапуске

func load(config: ConfigFile) -> void:
    _last_read_time = config.get_value("cooldown", "last_read_time",
                                        Time.get_unix_time_from_system() - COOLDOWN_SECONDS)
    _identity_at_last_read = config.get_value("cooldown", "identity_at_read", 0)
```

### UX при заблокированном чтении

> *«Мысли ещё не улеглись.»*

Без таймера и цифр — сохраняет атмосферу.

## Альтернативы

**Time.get_ticks_msec()** — отклонено: сбрасывается при перезапуске Godot, не подходит для персистентного cooldown.

**Только Identity-порог** — отклонено: обходится прокачкой через другие предметы без смысловых действий.

**Счётчик диалогов** — отклонено: не отражает смысловой нагрузки, легко обходится.

## Последствия

**Плюсы:**
- Cooldown привязан к смыслу, а не времени
- Легко расширяется: добавить новый триггер = одна строка сигнала
- `Time.get_unix_time_from_system()` корректно работает между сессиями

**Минусы:**
- Флаги quest/combat сбрасываются при перезапуске — игрок может перезапустить для обхода. Для пилота приемлемо.
- В v2 при добавлении Combat нужно подключить сигнал `on_combat_occurred`.
