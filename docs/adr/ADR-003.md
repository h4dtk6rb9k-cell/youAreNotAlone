# ADR-003: Изометрический движок на Godot 4

## Статус: Принято

## Контекст

GDD написан под Unity с классами IsoGrid, IsoCamera, IsoTileMap, IsoCharacter, IsoInput.
Проект ведётся на Godot 4 / GDScript — Unity-классы не существуют.
Необходимо реализовать эквивалентную изометрическую систему средствами Godot 4,
сохранив математику и формулы из GDD без изменений.

Параметры из GDD:
- Тайл: ромб 64×32 px (2:1 изометрия)
- OrthoSize = 5.859375 → zoom = 1 / 5.859375 ≈ 0.1707
- SortOrder(tx, ty) = (tx + ty) * 16
- TileToWorld(tx, ty) = ((tx−ty)*0.5, (tx+ty)*0.25)
- Персонаж: 64×96 px, pivot нижний центр (0.5, 0.0)
- 8 направлений: S/SE/E/NE/N/NW/W/SW

Стек: Godot 4, GDScript.

## Решение

### Структура сцены

```
IsoScene (Node2D)
├── TileMapLayer          ← изометрический тайлмап (встроен в Godot 4)
├── ObjectsLayer (Node2D) ← пропсы и NPC, y_sort_enabled = true
│   ├── IsoCharacter (CharacterBody2D)
│   ├── Prop_Bed (StaticBody2D)
│   └── ...
└── UILayer (CanvasLayer)
```

### IsoGrid — математика тайлов

```gdscript
# iso/iso_grid.gd
class_name IsoGrid

const TILE_WIDTH: int = 64
const TILE_HEIGHT: int = 32

# TileToWorld: формула из GDD без изменений
static func tile_to_world(tx: int, ty: int) -> Vector2:
    return Vector2(
        (tx - ty) * TILE_WIDTH * 0.5,
        (tx + ty) * TILE_HEIGHT * 0.5
    )

# WorldToTile (обратная)
static func world_to_tile(world: Vector2) -> Vector2i:
    var tx = (world.x / (TILE_WIDTH * 0.5) + world.y / (TILE_HEIGHT * 0.5)) * 0.5
    var ty = (world.y / (TILE_HEIGHT * 0.5) - world.x / (TILE_WIDTH * 0.5)) * 0.5
    return Vector2i(int(round(tx)), int(round(ty)))

# SortOrder: z_index для алгоритма художника
static func sort_order(tx: int, ty: int) -> int:
    return (tx + ty) * 16

static func sort_order_from_world(world: Vector2) -> int:
    var tile = world_to_tile(world)
    return sort_order(tile.x, tile.y)
```

### IsoCamera — камера

```gdscript
# iso/iso_camera.gd
class_name IsoCamera
extends Camera2D

# OrthoSize = 750 / 64 / 2 = 5.859375
# Godot zoom: меньше значение = дальше; pixel-perfect zoom = 1.0
# Для OrthoSize 5.859375: zoom = Vector2(1.0, 1.0) при viewport 750px высотой
# Настраивается под целевое разрешение в Project Settings

func _ready() -> void:
    zoom = Vector2(1.0, 1.0)   # pixel-perfect; подстроить под iOS viewport
    position_smoothing_enabled = false

func _process(_delta: float) -> void:
    # Pixel-snap: аналог LateUpdate в Unity
    global_position = global_position.round()
```

### TileMapLayer — тайлмап

Godot 4.3+ имеет встроенный `TileMapLayer` с нативной изометрией.

```
TileMapLayer Inspector:
  Tile Set → создать TileSet
    Tile Shape: Isometric
    Tile Layout: Diamond Down
    Tile Size: Vector2i(64, 32)
  Y Sort Origin: 0
```

Шахматный пол (тайл A/B) реализуется через два варианта тайла в TileSet и расстановку по условию `(tx + ty) % 2`.

```gdscript
# Процедурная расстановка пола (Квартира: 25×8, origin −12,−4)
func build_floor(tilemap: TileMapLayer, width: int, height: int, origin: Vector2i) -> void:
    for tx in range(origin.x, origin.x + width):
        for ty in range(origin.y, origin.y + height):
            var variant = (tx + ty) % 2   # 0 = тайл A, 1 = тайл B
            tilemap.set_cell(Vector2i(tx, ty), 0, Vector2i(variant, 0))
```

### IsoCharacter — персонаж

```gdscript
# iso/iso_character.gd
class_name IsoCharacter
extends CharacterBody2D

const MOVE_SPEED: float = 3.5 * 64.0   # MoveSpeed из GDD × TILE_WIDTH
const DIRECTIONS = ["s","se","e","ne","n","nw","w","sw"]

var _target_world: Vector2 = Vector2.ZERO
var _facing: String = "s"
var _moving: bool = false

@onready var sprite: Sprite2D = $Sprite2D

func move_to(world_pos: Vector2) -> void:
    _target_world = world_pos
    _moving = true

func set_facing(dir: String) -> void:
    _facing = dir
    _update_sprite()

func _physics_process(delta: float) -> void:
    if not _moving:
        return
    var diff = _target_world - global_position
    if diff.length() < 2.0:
        global_position = _target_world
        _moving = false
        return
    velocity = diff.normalized() * MOVE_SPEED
    move_and_slide()
    # Pixel-snap
    global_position = global_position.round()
    # z_index для сортировки
    z_index = IsoGrid.sort_order_from_world(global_position)
    # Обновить направление по вектору движения
    _facing = _vector_to_dir(velocity)
    _update_sprite()

func _update_sprite() -> void:
    # NW/W/SW — зеркало NE/E/SE
    var dir = _facing
    var flip = false
    if dir in ["nw", "w", "sw"]:
        dir = {"nw":"ne","w":"e","sw":"se"}[dir]
        flip = true
    sprite.texture = RuntimeArtLibrary.get_character_sprite(name, dir)
    sprite.flip_h = flip

static func _vector_to_dir(v: Vector2) -> String:
    var angle = v.angle()
    var idx = int(round(angle / (PI / 4.0))) % 8
    return DIRECTIONS[(idx + 8) % 8]
```

### IsoInput — тапы

```gdscript
# iso/iso_input.gd
class_name IsoInput
extends Node

signal on_world_tap(world_pos: Vector2)
signal on_object_tap(body: Node)

func _unhandled_input(event: InputEvent) -> void:
    if not event is InputEventScreenTouch and not event is InputEventMouseButton:
        return
    if event is InputEventMouseButton and not event.pressed:
        return
    if event is InputEventScreenTouch and not event.pressed:
        return

    var screen_pos = event.position
    var world_pos = get_viewport().get_canvas_transform().affine_inverse() * screen_pos

    # Проверка попадания в объект
    var space = get_viewport().world_2d.direct_space_state
    var query = PhysicsPointQueryParameters2D.new()
    query.position = world_pos
    var hits = space.intersect_point(query)
    if hits.size() > 0:
        on_object_tap.emit(hits[0].collider)
    else:
        on_world_tap.emit(world_pos)
```

### RuntimeArtLibrary — загрузка спрайтов

```gdscript
# art/runtime_art_library.gd
class_name RuntimeArtLibrary

# Загрузка: Assets/Resources/Art/Generated/character_{name}_{dir}.png
static func get_character_sprite(char_name: String, dir: String) -> Texture2D:
    var path = "res://Assets/Resources/Art/Generated/character_%s_%s.png" % [char_name, dir]
    return load(path)

static func get_prop_sprite(prop_name: String) -> Texture2D:
    var path = "res://Assets/Resources/Art/Generated/prop_%s.png" % prop_name
    return load(path)
```

## Альтернативы

**Ручной изометрический тайлмап (без TileMapLayer)** — отклонено: Godot 4.3 имеет нативную изо-поддержку, велосипед не нужен.

**Node3D с ортографической камерой** — отклонено: избыточно для 2D пиксель-арта, усложняет сортировку и спрайтовую анимацию.

**y_sort_enabled на TileMapLayer** — включён, обеспечивает автоматическую сортировку пропсов. Персонажи управляют z_index вручную через `sort_order_from_world()` для точного контроля.

## Последствия

**Плюсы:**
- Формулы TileToWorld / SortOrder из GDD сохранены без изменений
- TileMapLayer с нативной изометрией — минимум кода для тайлмапа
- Pixel-snap встроен в Project Settings — не нужен LateUpdate-хак
- IsoInput через сигналы — легко тестировать

**Минусы:**
- `RuntimeArtLibrary` использует `load()` синхронно — для v2 заменить на `ResourceLoader` с preload
- Направление персонажа через угол вектора даёт погрешность на диагоналях — добавить порог в v2
- TileMapLayer требует Godot 4.3+; на 4.2 использовать TileMap с одним слоем
